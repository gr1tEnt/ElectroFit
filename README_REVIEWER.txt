================================================================================
  ElectroFit — інструкція для перевіряючого (рецензента)
================================================================================

Вітаємо! Цей проєкт повністю контейнеризований за допомогою Docker.
Вам НЕ потрібно встановлювати Java, Node.js, Maven або PostgreSQL окремо.

--------------------------------------------------------------------------------
ЩО ПОТРІБНО ВСТАНОВИТИ (лише одне)
--------------------------------------------------------------------------------

  Docker Desktop для Windows
  https://www.docker.com/products/docker-desktop/

  Після встановлення запустіть Docker Desktop і дочекайтесь, поки він
  повністю завантажиться (іконка кита в треї стане стабільною).

--------------------------------------------------------------------------------
ЯК ЗАПУСТИТИ ПРОЄКТ (один подвійний клік)
--------------------------------------------------------------------------------

  1. Розпакуйте архів проєкту (якщо він у ZIP).
  2. Відкрийте папку проєкту ElectroFit.
  3. Двічі клацніть файл:  START.bat
  4. Дочекайтесь завершення збірки (перший раз — 5–15 хвилин).
  5. Відкрийте в браузері:  http://localhost:3000

--------------------------------------------------------------------------------
АДРЕСИ СЕРВІСІВ
--------------------------------------------------------------------------------

  Веб-сайт (магазин):     http://localhost:3000
  Backend API:            http://localhost:8080
  Swagger (документація): http://localhost:8080/swagger-ui.html
  База даних PostgreSQL:  localhost:5432
                            база: electrofit
                            користувач: postgres
                            пароль: postgres

--------------------------------------------------------------------------------
СКЛАД ПРОЄКТУ В DOCKER
--------------------------------------------------------------------------------

  db         — PostgreSQL 15 (база electrofit)
  backend    — Java Spring Boot (порт 8080)
  frontend   — Next.js React (порт 3000)

--------------------------------------------------------------------------------
ЯК ЗУПИНИТИ
--------------------------------------------------------------------------------

  У вікні START.bat натисніть Ctrl+C, потім закрийте вікно.

  Або в терміналі в папці проєкту виконайте:
    docker compose down

--------------------------------------------------------------------------------
МОЖЛИВІ ПРОБЛЕМИ
--------------------------------------------------------------------------------

  • «Docker Desktop не запущений» — увімкніть Docker Desktop і спробуйте знову.
  • Порт 3000 або 8080 зайнятий — закрийте інші програми на цих портах.
  • Повільна перша збірка — це нормально; наступні запуски будуть швидшими.

--------------------------------------------------------------------------------
ПРИМІТКА
--------------------------------------------------------------------------------

  Backend (Spring Boot) знаходиться в корені репозиторію; Dockerfile для нього
  розміщено в папці backend/. Frontend — у папці frontend/.

  Дякуємо за перегляд проєкту ElectroFit!
